« Qui est qui dans mon zoo ? »

La plupart des outils vous font chercher.
WhosWhoZoo sait déjà.

Il charge tout ce que vous avez enregistré sur les personnes et répond à partir de ça — instantanément et complètement. Comme parler à votre propre mémoire.

Vos trois niveaux de mémoire

🖥️Actif — votre bureau
Quatre fichiers toujours disponibles pour Claude : people.md, reflections.md, fragments.md, loops.md. Chaque conversation les charge automatiquement. C'est votre mémoire de travail — gardez-la légère et à jour.
📦Archives — votre classeur
Les anciens enregistrements dont vous n'avez pas besoin chaque jour mais auxquels vous souhaitez toujours accéder. Appuyez une fois sur 📦 Archives pour inclure les fichiers d'archives dans le chat et la recherche. Utilisez /archive-review pour laisser l'IA suggérer ce qui est prêt à y être déplacé.
🔐Stockage froid — rarement consulté, jamais chargé automatiquement
Les enregistrements que vous souhaitez conserver à long terme mais dont vous avez rarement besoin. Les fichiers de stockage froid ne sont jamais suggérés pour le nettoyage et ne sont jamais chargés automatiquement — ils ne s'ouvrent que lorsque vous le demandez. Utilisez /deep [nom] pour y déplacer un enregistrement. Lancez /recall [nom] pour rechercher dans le stockage froid, ou /recall seul pour parcourir tout ce qu'il contient.
Déplacer des enregistrements entre les niveaux
Actif → Archives : /archive [nom] ou /archive-review
Archives → Stockage froid : /deep [nom] ou /deep-review
N'importe quel niveau → Actif : /restore [nom]

Comment ça marche

💾Votre mémoire, vos fichiers
Vos notes vivent dans votre propre compte — pas sur les serveurs de WhosWhoZoo. Vous pouvez tout exporter ou supprimer à tout moment. Il y a 4 fichiers actifs (people, reflections, fragments, loops), 4 fichiers d'archives pour les anciens enregistrements, et 4 fichiers de stockage froid pour les enregistrements à long terme rarement consultés.
🧠Claude lit tout, à chaque fois
Chaque question charge toute votre mémoire active dans Claude avant de répondre : le fichier entier, pas un résultat de recherche. Aucune supposition sur les notes qui comptent, et vos archives sont accessibles d'un seul geste quand vous en avez besoin, ce qui lui permet d'établir des liens entre les personnes et les sujets.
📦Les archives maintiennent la légèreté
Les enregistrements dont vous n'avez plus besoin quotidiennement sont déplacés vers les archives. Utilisez le bouton 📦 pour inclure les fichiers d'archives dans le chat et la recherche. Le stockage froid est séparé — utilisez /recall pour le rechercher. Les enregistrements du stockage froid ne sont jamais chargés automatiquement.
🔒Mémoire organisée — sans bruit extérieur
Claude ne lit que ce que vous avez enregistré — pas internet, pas les données des autres. C'est pourquoi les réponses s'appuient sur vos propres notes plutôt que sur des connaissances générales du web. Un conseil pratique : quand deux personnes partagent le même prénom, ou que vous hésitez sur l'orthographe, donnez le nom complet. Un nom partiel ou mal orthographié est le seul cas où Claude peut tomber sur le mauvais dossier, ou affirmer qu'une personne est absente alors qu'elle est bien là — si cela arrive, réinitialisez le contexte et redemandez avec le nom complet.
🎙Voix en entrée, voix en sortie
Appuyez sur le micro pour entrer en mode conversation. Parlez naturellement. L'app transcrit, envoie à Claude et lit la réponse à voix haute — avec les URL et le code remplacés par des indications verbales pour rester agréable à écouter.

Confidentialité et coût

🛡️Vos données n'entraînent jamais des modèles d'IA
WhosWhoZoo utilise l'API Anthropic — pas le site web Claude.ai. L'utilisation de l'API est explicitement exclue de l'entraînement des modèles selon les conditions d'Anthropic. Vos notes sont traitées par Claude pour répondre à vos questions, mais Anthropic ne les stocke jamais à long terme ni ne les utilise pour améliorer un modèle d'IA. Si vous utilisez des réponses vocales, le texte prononcé passe par ElevenLabs ou OpenAI TTS — également sous des conditions d'API qui interdisent l'utilisation pour l'entraînement.
☁️Stocké en périphérie, pas sur un serveur central
Vos fichiers mémoire sont stockés sur le réseau mondial de Cloudflare — la même infrastructure qui alimente des millions de sites web. Il n'y a pas de base de données WhosWhoZoo, pas de compte à pirater. Vos données vivent dans votre compte Cloudflare, et dans l'application c'est votre phrase secrète qui les déverrouille. À savoir : le jeton d'API Cloudflare utilisé lors de l'installation peut lire ces fichiers directement, sans votre phrase secrète — c'est précisément pourquoi nous recommandons de le supprimer une fois l'installation terminée. Les photos (si activées) sont stockées dans le stockage d'objets Cloudflare R2 — le niveau gratuit est de 10 Go/mois, bien qu'une carte bancaire enregistrée soit requise pour activer R2, même gratuitement.
💳Sans abonnement — rechargez un solde, utilisez ce dont vous avez besoin
Vous ajoutez des crédits à vos propres comptes Anthropic et OpenAI (comme des soldes prépayés) et vous ne payez que ce que vous utilisez. Cela représente quelques dollars par mois au départ, et cela augmente à mesure que votre mémoire grandit — chaque question renvoie tout ce que vous avez écrit, donc une mémoire volumineuse et utilisée depuis longtemps coûte plus cher par question qu'une petite. Tapez /costs à tout moment pour voir votre total cumulé, et fixez un plafond quotidien dans les Paramètres. Les réponses vocales utilisent OpenAI TTS (voix Marin & Onyx, paiement à l'utilisation depuis le même solde OpenAI) ou ElevenLabs (voix Brittney & Callum — également au paiement à l'utilisation ; quelques dollars de crédit ElevenLabs couvrent une utilisation normale). Aucun abonnement obligatoire — pour quoi que ce soit.

Audit mémoire

L'audit recherche des problèmes d'intégrité dans votre mémoire — caractères cassés dans les métadonnées, en-têtes mal formés, incohérences de dates — séparément des nudges du cycle de vie de la mémoire basés sur la taille.

/audit exécute l'analyse rapide gratuite sur vos fichiers actifs et archivés. /audit deep ajoute la détection de quasi-doublons et d'incohérences de noms assistée par Haiku, ainsi que des vérifications d'intégrité des photos : références cassées (une photo listée dans une fiche mais absente du stockage) et fichiers orphelins (dans le stockage mais référencés nulle part). Coûte quelques centimes — vous confirmez l'estimation avant l'exécution. /audit ignored liste les résultats que vous avez rejetés et vous permet de désactiver l'ignoré des entrées individuelles.

Chaque résultat a deux actions : Ouvrir (accède à la fenêtre d'édition de l'enregistrement pour que vous puissiez le corriger) et Ignorer (supprime ce problème précis dans les futurs audits).

⚡ Haiku / Sonnet Appuyez pour changer de modèle d'IA. Haiku est rapide et économique. Sonnet est plus intelligent pour les tâches complexes.
📋 Copier le chat Copie la conversation complète dans le presse-papiers avec les étiquettes Vous / WhosWhoZoo — utile pour partager ou déboguer.
🎙 Mode vocal Mode conversation complet — parlez et écoutez la réponse. Le bouton 🎙 dans l'en-tête du chat ouvre la superposition orbe en plein écran. Après avoir parlé, un bouton Envoyer apparaît — appuyez dessus (ou sur l'orbe) pour envoyer. Appuyez sur ✕ pour quitter. Maintenez l'orbe enfoncé pour entrer en mode dictée de journal. Un bouton micro séparé dans la barre de saisie gère la voix-vers-texte pour le mode chat (appuyez pour démarrer, appuyez pour arrêter).
⚙ Paramètres Mettez à jour votre URL Worker, changez votre mot de passe, configurez le déverrouillage par empreinte digitale, gérez les remplacements de clés API (Anthropic, OpenAI, ElevenLabs), configurez le verrouillage automatique, définissez un plafond de dépenses Anthropic quotidien ($1/$2/$5/$10/Jamais — par défaut $1/jour), choisissez votre langue d'affichage, activez ou désactivez Token Saver (activé par défaut — efface l'historique de conversation à la sortie du mode vocal pour économiser des tokens de contexte ; désactivez-le pour conserver l'historique entre les sessions vocales), ou déconnectez-vous. Modes de saisie vocale

Deux moteurs de transcription sont disponibles. Basculez entre eux dans Paramètres → Saisie vocale. Le paramètre persiste entre les sessions.

⚡Auto — rapide, gratuit, natif du navigateur
Utilise l'API Web Speech Recognition intégrée du navigateur. Instantané — la transcription apparaît au fur et à mesure que vous parlez. Aucun crédit API utilisé. La précision dépend de votre navigateur et de votre accent. Idéal pour les questions rapides et la plupart des usages quotidiens. Sur iOS, Auto bascule toujours vers Whisper car iOS Safari ne prend pas en charge la Web Speech API.
🎙Whisper — précis, coût minime, légère latence
Envoie l'audio au modèle Whisper-1 d'OpenAI via l'endpoint /transcribe de votre worker. Plus précis qu'Auto — surtout pour les noms, les termes techniques et les environnements plus silencieux. Coûte une infime fraction de centime par clip (facturé sur votre compte OpenAI). Ajoute un temps de réponse de 1 à 3 secondes pendant le traitement de l'audio. Nécessite que votre clé API OpenAI soit configurée.
🌐Langue vocale — Whisper uniquement
Paramètres → Langue vocale. Définit la langue que Whisper écoute : English, हिन्दी (Hindi), Español ou Français. Par défaut : English. Fixer la langue empêche Whisper de générer du texte incorrect sur un audio quasi-silencieux — un défaut connu quand aucune langue n'est précisée. S'applique uniquement au mode Whisper ; Auto utilise la reconnaissance vocale du navigateur, qui détecte la langue automatiquement.
💾Token Saver — Paramètres → Token Saver
Contrôle ce qui arrive à la conversation lorsque vous fermez le mode vocal. Activé (par défaut) : l'historique de conversation est effacé à la sortie — libère des tokens de contexte pour que la prochaine session démarre à zéro. Désactivé : l'historique de conversation est conservé — vous pouvez reprendre le chat exactement là où vous l'avez laissé après avoir fermé le mode vocal. Désactivez-le si vous voulez conserver le contexte entre les sessions vocales.

Conseils

Posez des questions naturellement. Vous n'avez pas besoin de commandes pour la plupart des choses. « Qui est Adam ? » ou « que sais-je sur le projet PTMM ? » fonctionnent comme de simples questions.
Les mots seuls déclenchent la recherche par balise. Tapez un seul mot ou une expression sans verbe et l'app recherche exhaustivement cette balise dans tous les enregistrements avant de répondre.
Ajoutez une portée de fichier à n'importe quelle recherche. /edit people adam limite à people.md. /archive loops archive uniquement depuis loops.md.
Les archives maintiennent Claude rapide. Déplacez les enregistrements périmés vers les archives. Ils restent consultables avec le bouton 📦 Archives activé — ils ne sont simplement pas chargés à chaque message du chat.
La voix ignore les URL et le code. En mode conversation, les liens disent « voir le lien dans le chat » et le code dit « voir le code dans le chat » — le contenu complet est toujours dans la bulle de chat.
/r est votre soupape de réinitialisation. Si une conversation déraille, /r efface le contexte sans perdre vos fichiers mémoire.
Ajoutez des enregistrements du stockage froid au chat. Utilisez /recall [nom] pour trouver un enregistrement du stockage froid, puis appuyez sur « Utiliser dans le chat » — une barre violette apparaît au-dessus du champ de saisie confirmant que l'enregistrement est chargé. Claude le verra dans chaque message jusqu'à ce que vous appuyiez sur effacer.
Les fichiers mémoire sont en Markdown. Lorsque vous modifiez des enregistrements directement avec /edit, les en-têtes utilisent ##, les puces utilisent -, et le gras utilise **texte**. Vous n'êtes pas sûr de la syntaxe ? Syntaxe Markdown de base →
Installez sur votre écran d'accueil pour une expérience d'app native. L'app fonctionne comme une app installée en plein écran sur les deux plateformes — sans App Store requis.

Chrome, Edge ou Samsung Internet : après connexion, repérez une bannière Installer en un tap au-dessus du champ de message — appuyez dessus, c'est fait. N'apparaît pas sur Safari/iPhone (cette option n'existe pas là-bas) ni si l'app est déjà installée.

Android (manuel) : Ouvrez l'URL de votre app dans Chrome → appuyez sur le menu à trois points → Ajouter à l'écran d'accueil.
iPhone : Ouvrez l'URL de votre app dans Safari (pas Chrome) → appuyez sur le bouton Partager (carré avec flèche) → Sur l'écran d'accueil.

Une fois installée, l'app se lance sans le chrome du navigateur. Le déverrouillage biométrique (empreinte digitale ou Face ID) peut également devenir disponible s'il ne fonctionnait pas dans l'onglet du navigateur.
